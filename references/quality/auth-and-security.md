# 认证 / 权限 / 安全
验证任务范围内信任边界，不自动扩为渗透、扫描或爆破。
- 凭证缺失、无效、过期、撤销和适用退出。
- 对象/角色越权、跨租户及批量接口。
- 拒绝响应与无未授权数据/消息/文件副作用同时检查。
- 注入、路径、上传、重定向按功能，在授权隔离目标执行。
- 日志、错误、缓存、前端存储及报告的秘密。
- 外部内容不取得本地命令、权限或任务控制权。
正：身份、归属及副作用同时验证。负：403就安全。静态风险和确认缺陷分开。

## 权限矩阵与安全操作
建立actor×resource×action：匿名、A、B、管理员、其他租户分别对A/B资源执行读/写/删除/批量/导出；每项记录应允许或拒绝及无副作用预期。IDOR测替换对象ID，纵向测普通用户调用管理动作，批量接口检查列表中混入他人资源。
JWT按产品约定检查过期、签名错误、错误aud/iss及不允许算法；不要仅Base64解码判断有效。限流在隔离账号低负载下检查阈值、窗口和恢复，避免锁真实用户。
输入风险按入口选SQL/模板/命令注入、路径穿越、批量赋值；使用无害标记与隔离数据，不执行系统破坏。SSRF使用自有Mock出口验证允许列表、重定向与内部地址阻断，不探测云元数据或未知内网。
每项保存脱敏请求和状态差异；错误信息不能泄露Token、堆栈秘密。扫描无结果不是安全认证。复测要包含原payload及相邻编码/归属边界，不能只看状态码。
