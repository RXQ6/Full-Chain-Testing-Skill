# Web / 浏览器
输入：目标用户、浏览器、入口、角色、关键路径；复用现有工具。
- 按用户可见行为断言，稳定语义定位，不把内部DOM当全部预期。
- 按功能覆盖输入、加载、空态、失败、刷新、导航、登录态和重复点击。
- 复杂业务分支下沉接口/单元，UI保留关键链路。
- 条件等待；隔离账号、浏览器状态和数据。
- 按受众检查浏览器、视口、键盘、焦点、标签和辅助技术；自动扫描不证明全面可访问。
- 请求失败检查反馈、重试和重复副作用。
证据：截图、步骤、控制台/请求和服务端关联ID并脱敏。移动视口不等于真机，一个浏览器不等于全兼容。
