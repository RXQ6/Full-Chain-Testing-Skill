# 桌面 / IPC / 安装更新
识别系统、安装版与开发版；混合应用同时加载Web/API。
- 冷启动、重复启动、单实例、多窗口、关闭/退出、托盘和子进程清理。
- 关闭中任务、崩溃、未保存数据和重启后的业务恢复。
- IPC来源、权限、参数、错误及原生能力边界。
- 中文/空格路径、权限、只读、文件锁、磁盘不足和资源释放。
- 安装、升级、中断、失败回滚和用户数据保留。
- 文件关联、通知、开机启动仅按产品功能。
证据：系统、安装包、进程、窗口、日志及数据。使用测试用户目录，不删真实配置。开发版不代表打包版。
正：更新后历史数据可读、旧进程退出。负：安装器退出0就升级无损。

## 执行记录与反证步骤
1. 固定被测版本、目标平台、输入和起始状态；先复现一条最小合法流程。
2. 选择本专项最重要的失败边界，登记需求ID、操作、独立预期和可观察副作用。
3. 复用项目已有工具：界面使用现有UI工具，库/脚本使用语言测试入口，设备使用台架/协议客户端。工具不可用时不要假造运行。
4. 对隔离副本施加一个已知违例，核对原断言失败；无法安全注入时保留验证局限。
5. 保存实际步骤、输出和状态差异，清理本次资源。模拟环境、平台和设备型号写入结论。
反例：只记录工具退出码而未验证用户结果；截图看似正常但数据错误；恢复后重复执行外部动作。三者均不能作为通过。
